# Changelog

Notable changes in each release, newest first. The format follows
[Keep a Changelog](https://keepachangelog.com/en/2.0.0/), and versions follow
[Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-10-30

### Added

- `claude [<profile>]` starts Claude Code in a profile, or the one used last.
- `claude-profiles` lists, adds, removes and renames profiles.
- One shared copy of CLAUDE.md, skills, plugins, settings and every session;
  logins and `account-settings.json` stay per profile.
- bash, zsh and fish, with an `install.sh` that checks the requirements first.
